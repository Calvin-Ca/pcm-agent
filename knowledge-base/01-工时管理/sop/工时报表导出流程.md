# 工时报表导出流程

## 1. 流程目的

为项目经理、部门负责人、HR等需要分析工时数据的角色提供规范的报表导出操作指引，覆盖按项目、按员工、按时间段、按工时类型等多种维度，并明确数据安全和保密要求。目标是使常规导出操作单次不超过5分钟、月度报表准确率达到99%以上。

## 2. 适用场景

- 项目经理向客户或PMO汇报项目工时投入
- 部门负责人开展月度/季度工时分析
- 人力资源部年度工时审计抽查
- 财务部门为成本分摊与项目核算导出工时数据
- 项目结项时的工时数据归档

## 3. 角色与职责

| 角色 | 职责 |
|------|------|
| 项目经理 | 导出本项目工时报表，对外披露需脱敏 |
| 部门负责人 | 导出本部门工时报表，重点分析人均工时与项目分布 |
| HR | 导出全公司工时报表，做合规分析 |
| 财务 | 导出可计费工时报表，用于成本核算 |
| 系统管理员 | 维护报表模板，处理导出权限申请 |

## 4. 操作步骤

### Step 1: 确认导出权限

- 操作人：导出申请人
- 输入：需要导出的数据范围
- 动作：登录工时系统，查看"我的报表权限"；权限不足的，向系统管理员或部门负责人申请；导出范围超过本部门的，需要HR授权。
- 输出：可用导出范围确认
- 时限：当日完成权限自查

### Step 2: 选择报表模板

- 操作人：导出申请人
- 输入：业务用途（汇报/审计/核算/归档）
- 动作：进入"报表中心"，根据用途选择对应模板：项目工时月报、员工工时分析、可计费工时表、跨部门工时表等共15种内置模板；不满足需求的，使用"自定义模板"功能。
- 输出：已选定的报表模板
- 时限：5分钟内完成模板选择

### Step 3: 设置筛选条件

- 操作人：导出申请人
- 输入：维度参数（时间、项目、部门、员工、工时类型）
- 动作：填写起止日期（最长支持3年范围）；勾选项目、部门或员工；选择工时类型；高级筛选支持工时数阈值、关键字匹配等。
- 输出：筛选条件已锁定
- 时限：5分钟内完成

### Step 4: 预览数据并校验

- 操作人：导出申请人
- 输入：当前筛选条件
- 动作：点击"预览"，查看前100条数据是否符合预期；核对总工时数、人数、项目数与预期是否一致；不一致时调整筛选条件。
- 输出：预览数据通过校验
- 时限：3分钟内完成

### Step 5: 选择导出格式与执行

- 操作人：导出申请人
- 输入：报表用途
- 动作：选择导出格式（Excel xlsx / CSV / PDF）；勾选是否包含图表；点击"开始导出"；大数据量（超过10万行）任务进入后台队列，完成后通过站内消息通知。
- 输出：本地下载到的报表文件
- 时限：常规导出实时完成；大数据量导出在30分钟内完成

### Step 6: 文件加密与分发

- 操作人：导出申请人
- 输入：导出的报表文件
- 动作：涉及对外披露的报表必须使用WinRAR/7-Zip加密压缩，密码通过其他渠道告知接收方；涉及成员个人工时的，需脱敏（隐去姓名后4位、工号中段）；通过企业邮件或企业微信安全文件传输。
- 输出：加密后的报表文件
- 时限：导出后立即处理

## 5. 异常处理

**异常一：导出的报表数据与系统看到的不一致**。可能因为筛选条件不同或权限范围不同；先复核筛选条件，再联系系统管理员排查时区或权限问题。

**异常二：大数据量导出失败或超时**。建议拆分导出范围（按部门或月份分批）；或在系统低峰期（如夜间）使用后台队列；连续失败的，向系统管理员开工单。

**异常三：报表外发后发现含有敏感字段**。立即通知接收方删除原文件，使用脱敏后版本重新发送；同时按公司信息安全制度上报到信息安全负责人。

## 6. 时效要求

| 节点 | SLA |
|------|-----|
| 常规导出（≤1万行） | 3分钟内完成 |
| 中量导出（1-10万行） | 10分钟内完成 |
| 大量导出（>10万行） | 30分钟内完成 |
| 异常工单处理 | 1个工作日内响应 |
