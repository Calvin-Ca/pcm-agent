# 请假申请流程

## 1. 流程目的

规范员工各类请假（病假、事假、婚丧产假、年假等）的申请、审批与销假全流程，确保请假记录准确、审批透明、考勤与薪资计算一致。

## 2. 适用场景

- 员工因个人事务请事假。
- 员工因病请病假。
- 员工请婚假、丧假、产假、陪产假等特殊假期。
- 员工使用年假。
- 员工因不可抗力无法到岗的紧急请假。

## 3. 角色与职责

| 角色 | 职责 |
|------|------|
| 申请人（员工） | 如实填写请假类型、时段、事由，上传证明材料 |
| 直属主管 | 一级审批，核实业务影响和替代方案 |
| 部门经理 | 二级审批，3 天以上假期的复核 |
| HR BP | 审核特殊假期合规性、证明材料、薪资影响 |
| 工时系统 | 记录、通知、状态流转、余额扣减 |

## 4. 操作步骤

**Step 1**：登录工时管理系统 → 请假申请。
- 操作人：员工
- 输入：请假类型、起止日期、事由、证明材料
- 动作：填写并提交
- 输出：待审批工单
- 时限：提前 3 个工作日

**Step 2**：直属主管一级审批。
- 操作人：主管
- 输入：待审批工单
- 动作：评估业务影响，决定通过/驳回/退回
- 输出：审批结果
- 时限：2 个工作日

**Step 3**：3 天以上自动转部门经理。
- 操作人：部门经理
- 输入：一级通过工单
- 动作：复核排期、人力替补
- 输出：最终结果
- 时限：2 个工作日

**Step 4**：HR BP 审核特殊假期。
- 操作人：HR BP
- 输入：婚丧产陪产假、病假 7 天以上工单
- 动作：核实证明材料、社保影响
- 输出：审核结果
- 时限：3 个工作日

**Step 5**：假期执行。
- 操作人：员工
- 输入：通过工单
- 动作：按假期安排离岗
- 输出：假期记录
- 时限：假期期内

**Step 6**：销假确认。
- 操作人：员工
- 输入：假期到期
- 动作：在系统销假，确认返岗
- 输出：销假完成
- 时限：返岗 1 个工作日内

## 5. 异常处理

- **紧急请假**：无法提前 3 天申请的，可先电话/即时通讯通知主管，返岗后 5 个工作日内补办。
- **证明材料缺失**：病假无证明的按事假处理；婚假无结婚证的按事假处理；产假无诊断书的暂缓审批。
- **审批超时**：主管 2 个工作日未审批的，系统升级至部门经理；超 3 个工作日未处理的视同默认通过。
- **销假逾期**：未按时销假的，系统按延期请假处理，逾期 3 天未补办的按旷工处理。

## 6. 时效要求

- 申请：提前 3 个工作日；
- 紧急补办：返岗后 5 个工作日；
- 单级审批：2 个工作日；
- HR 审核：3 个工作日；
- 销假：返岗 1 个工作日。
