# 外勤与远程办公考勤规则

## 1. 适用范围

本规则适用于员工因公外出（客户拜访、现场支持、会议等）和经批准在家远程办公的考勤管理。涵盖短期外勤（单日）、长期外派（连续5个工作日以上）、临时远程办公（单日）和周期性远程办公（固定每周若干天）等多种场景。

适用对象为公司全体正式员工；试用期员工申请远程办公需经部门负责人和HR双重审批。涉及子公司或分公司的外勤/远程办公，由当地考勤管理责任人参照本规则执行。

## 2. 定义与术语

- **外勤**：员工离开公司办公区域，前往客户现场、合作伙伴处或其他外部地点执行工作任务的行为。
- **远程办公**：员工经批准在家或其他非公司办公地点完成工作任务的行为。
- **外勤打卡**：员工在外勤地点通过手机APP进行的定位打卡。
- **远程打卡**：员工在远程办公地点通过手机APP或PC端进行的打卡。
- **外勤审批**：员工因公外出前，在系统中提交的包含外出时间、地点、事由的审批单。
- **远程办公审批**：员工申请远程办公前，在系统中提交的包含远程办公时间、原因、工作安排的审批单。

## 3. 核心规则

### 3.1 外勤考勤规则

员工因公外出前须提交外勤审批，审批通过后方可外出。外勤期间每日须完成2次打卡：出发打卡（离开公司时）和到达打卡（到达外勤地点时）；如外勤地点为公司外部，还需完成外勤打卡（在外勤地点的打卡）。外勤打卡通过手机APP定位完成，定位半径不超过外勤地点500米。单次外勤超过4小时的，须在系统中填写外勤工作日志（不少于50字）。

### 3.2 远程办公考勤规则

员工申请远程办公须提前1个工作日提交审批，审批通过后方可远程办公。远程办公期间每日须完成2次打卡：上班打卡和下班打卡，通过手机APP或PC端完成。远程打卡地址须与审批中登记的地址一致，偏差不超过200米。远程办公期间员工须保持企业IM在线，响应时间不超过30分钟。远程办公单日不得超过8小时，月度累计远程办公天数不得超过当月工作日总数的40%。

### 3.3 外勤与工时的关联

外勤期间的差旅时间（交通时间）按以下规则折算：单程交通时间不超过4小时的，按实际时间折算工时；单程超过4小时的，按4小时折算。外勤期间的工作时间按实际工作内容填报工时，与常规工时填报规则一致。远程办公期间的工作时间按实际工作内容填报工时，与在公司办公无区别。

### 3.4 审批权限与时限

单日外勤由直属上级审批；连续外勤超过3个工作日的，需部门负责人审批。单日远程办公由直属上级审批；周期性远程办公（每周固定天数）需部门负责人和HR双重审批。审批应在提交后1个工作日内完成；紧急外勤可先电话沟通后补审批。

## 4. 例外情况

**情况一：紧急客户故障**。因客户系统故障等紧急情况需要立即外出支持的，可先外出并在2小时内补交外勤审批；事后补审批需附客户故障工单或沟通记录。

**情况二：疫情或公共卫生事件**。因疫情等公共卫生事件需要全员远程办公的，由公司统一发布通知，无需个人提交远程办公审批。

**情况三：恶劣天气导致无法到岗**。因台风、暴雪等恶劣天气导致无法到公司办公的，经公司统一通知后，当日可转为远程办公，无需单独审批。

## 5. 处罚与追责

员工未经审批擅自外勤或远程办公的，当日考勤按旷工处理。员工在外勤/远程办公期间失联超过2小时且无合理解释的，按早退处理。员工远程办公期间从事与工作无关活动的（如长时间不在线、响应超时），经核实后扣减当日绩效并取消当月远程办公资格。

## 6. 附则

本规则自2026年1月1日起施行，由人力资源部负责解释。本规则与打卡规则与异常认定、考勤异常申报流程配套使用。远程办公政策每年至少评估1次，根据业务需要和员工反馈调整。
