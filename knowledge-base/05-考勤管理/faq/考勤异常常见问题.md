# 考勤异常常见问题

## Q1: 考勤异常有哪些类型？分别怎么处理？

**简答**：常见异常类型：漏打卡、迟到、早退、旷工、地点异常、时间异常；处理方式从自行补卡到申报审批不等。

**详细说明**：
考勤异常按类型和处理方式分类：
- **漏打卡**：忘记打卡或打卡失败，走"补卡申请流程"
- **迟到/早退**：超出打卡缓冲区的，按迟到早退处罚办法处理
- **旷工**：未请假缺勤，按旷工规则处理（扣工资+绩效）
- **地点异常**：打卡地点与登记地址偏差过大，走"考勤异常申报流程"
- **时间异常**：打卡时间与实际工作时间明显不符，走"考勤异常申报流程"
- **系统误判**：系统错误标记的异常，联系行政部或系统管理员核查

大多数异常（漏打卡、地点偏差）通过补卡或申报即可解决；涉及处罚的（迟到、旷工）需要按相应制度执行。

**相关制度**：考勤异常申报流程.md

## Q2: 我的考勤被标异常了，但我明明正常出勤了，怎么办？

**简答**：先确认异常类型，收集证据（企业IM在线记录、工作产出、同事证明等），然后通过对应流程申诉。

**详细说明**：
被误判为考勤异常时，处理步骤：
1. **确认异常类型**：登录系统查看具体是什么异常（漏打卡/地点异常/时间异常等）
2. **收集证据**：
   - 企业IM在线记录（证明当日在线工作）
   - 工作产出（代码提交、文档、邮件等）
   - 同事证明（如"当日一起开会"）
   - 系统截图（如打卡记录显示成功但系统仍标异常）
3. **选择流程**：漏打卡走"补卡申请"，其他异常走"考勤异常申报"
4. **提交申诉**：填写原因、上传证据
5. **等待审批**：直属上级2个工作日内处理

注意：申诉期间该异常不直接产生处罚；但如果是真实的迟到/旷工，申诉不会改变结果。

**相关制度**：考勤异常申报流程.md

## Q3: 考勤异常会影响我的工资和绩效吗？

**简答**：漏打卡补卡后不影响；迟到/早退扣绩效；旷工扣工资+绩效；地点异常修正后不影响。

**详细说明**：
不同异常对工资和绩效的影响：
- **漏打卡（已补卡）**：不影响工资和绩效
- **迟到/早退**：每次扣减绩效0.5-2分（按严重程度），取消当月全勤奖
- **旷工**：旷工半天扣当日工资50%+绩效3分；旷工1天扣当日工资100%+绩效5分
- **地点异常（已修正）**：不影响工资和绩效
- **时间异常（已修正）**：不影响工资和绩效

连续2个月出现考勤异常（迟到/早退累计超过10次）的，纳入部门负责人管理能力评估。所以偶尔一次异常不用太担心，但频繁异常需要重视。

**相关制度**：考勤管理制度.md、迟到早退处罚办法.md

## Q4: 设备故障导致打卡失败，算我的异常吗？

**简答**：不算，但需要2个工作日内向行政部报备，由行政部出具故障证明后按正常出勤处理。

**详细说明**：
因考勤设备故障（指纹机失灵、人脸识别失败、网络中断等）导致的打卡失败，员工不承担责任。处理流程：
1. 故障发生时立即截图或拍照保留证据
2. 2个工作日内向行政部报备（可通过企业微信或OA）
3. 行政部核查后出具"设备故障证明"
4. 凭证明在系统中标记为"设备故障-正常出勤"

注意：如果设备故障但你没有报备，系统会按漏打卡处理；所以即使确定是设备问题，也要走报备流程。

**相关制度**：打卡规则与异常认定.md

## Q5: 我能查到别人的考勤异常吗？

**简答**：普通员工只能查自己的；项目经理可查本项目成员的；部门负责人可查本部门的；HR可查全公司。

**详细说明**：
考勤异常查询权限严格按角色：
- **员工**：仅本人考勤异常
- **项目经理**：本项目成员的考勤异常（用于团队管理）
- **部门负责人**：本部门员工的考勤异常
- **HR**：全公司考勤异常（用于汇总分析和制度执行）

查询他人考勤异常需要合理的业务理由（如项目经理管理团队、HR做月度汇总），不得出于好奇或八卦目的查询。违规查询他人考勤数据的，按信息安全制度处理。

**相关制度**：考勤管理制度.md

## Q6: 考勤异常申报被驳回了，还能再申诉吗？

**简答**：可以申诉一次；如有新证据可二次申诉；同一事项一般只受理一次复议。

**详细说明**：
考勤异常申报被驳回后的申诉路径：
1. **首次申诉**：对直属上级的驳回决定不服，可向部门负责人申诉，3个工作日内处理
2. **二次申诉**：对部门负责人的决定仍不服，可向HR申诉，5个工作日内处理
3. **最终结论**：HR的决定为最终结论

申诉时需要提供新的证据或更充分的说明；如果只是重复之前的理由，申诉通过概率很低。建议被驳回后先与直属上级沟通，了解驳回的具体原因，有针对性地补充材料。

**相关制度**：考勤异常申报流程.md

## Q7: 系统显示我旷工了，但我那天请假了，怎么回事？

**简答**：可能是请假审批未同步到考勤系统；联系HR核查请假单状态，确认后修正考勤记录。

**详细说明**：
请假了但系统显示旷工，常见原因：
1. **请假审批未完成**：请假单还在审批流程中，未同步到考勤系统
2. **请假类型不匹配**：如请的是"事假"但系统按"旷工"处理（某些请假类型需要特殊审批）
3. **系统同步延迟**：请假审批已完成但考勤系统未及时同步
4. **请假单填写错误**：如请的是10月15日但填成了10月16日

处理步骤：先查看自己的请假单状态（是否已完成审批），再核对请假日期；如确认是系统问题，联系HR和系统管理员核查并修正。

**相关制度**：考勤管理制度.md

## Q8: 考勤异常记录会保留多久？影响我以后吗？

**简答**：考勤记录保留3年；已修正的异常不影响；未修正的异常（如迟到记录）保留在档案中，可能影响年度评优。

**详细说明**：
考勤数据的保留期限：
- **原始打卡记录**：保留3年
- **异常处理记录**：保留3年（含申诉、补卡、修正等）
- **处罚记录**：保留3年（与绩效档案同步）

已修正的异常（如漏打卡补卡后、地点异常修正后）不会留下负面记录。但未修正的异常（如真实的迟到记录）会保留在考勤档案中，可能影响：
- 年度全勤奖评选
- 年度优秀员工评选（部分奖项要求全年无迟到）
- 晋升评估中的"职业素养"维度

所以尽量保持良好的考勤记录，偶尔一次异常及时修正即可。

**相关制度**：考勤管理制度.md
