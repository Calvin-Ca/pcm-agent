## 重评分口径

- `query_timesheet.member_name` 与生产处理器解析后的 `user_id` 等价。
- 本周、上周、下周按生产系统提示定义为周一到周日；“本月至今”截止参考日。
- 当前部门 ID 以认证上下文注入值为准；项目名由生产处理器解析为项目 ID。
- 单次意外路由记为工具选择错误；同一轮内“工具名 + 完全相同参数”重复执行才记为重复调用。
- 原始 `results.jsonl` 保留不变，便于审计。
