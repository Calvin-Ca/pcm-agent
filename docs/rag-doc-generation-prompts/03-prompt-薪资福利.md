## R3. 内容质量约束

- **数字阈值至少 2 个**(如"每月 15 号发放"、"年终奖 ≥ 月薪 ×N"、"养老保险 8% / 16%")— 用阿拉伯数字
- **业务关键词至少 5 个**(基本工资 / 绩效奖金 / 五险一金 / 公积金 / 个税 / 加班费 / 福利津贴 等)
- **不允许使用具体人名、具体薪资数字** — 用"X 元"或"基本工资的 N 倍"等占位
- **每个章节标题严格用 `## N. 标题名` 格式**
- **政策类要明确区分"法定标准"和"公司加码"**(如:法定养老保险 8%,公司缴 16%)
- **避免空话套话**
