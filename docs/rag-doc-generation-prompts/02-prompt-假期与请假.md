# 全局规范

## R1. Frontmatter(YAML)— 必填

每篇 `.md` 文档必须以下面这种 YAML frontmatter 开头:

```yaml

```

## R2. 字数与结构

| 体裁 | 总字数 | 结构要求 |
|------|--------|---------|
| policy | 1500-3000 字 | 6 章(适用范围 / 定义 / 核心规则 / 例外 / 处罚 / 附则) |
| sop | 1200-2500 字 | 7 章(目的 / 适用场景 / 角色职责 / 操作步骤 / 异常处理 / 时效 / 表单) |
| faq | 1500-3000 字 | 至少 8 个 Q&A,每个 Q 配 1 段简答 + 1-3 段详细说明 |
| case | 1000-2000 字 | 5 章(案例背景 / 涉及问题 / 处理过程 / 结论与启示 / 涉及制度) |

## R3. 内容质量约束

- **数字阈值至少 2 个**(如"提前 3 天申请"、"调休 1 年内有效"、"病假 1 个月内 < 3 天")— 用阿拉伯数字
- **业务关键词覆盖至少 5 个**
- **不允许使用具体人名、具体项目名、真实部门名** — 必须泛指
- **每个章节标题严格用 `## N. 标题名` 格式**
- **避免空话套话**
