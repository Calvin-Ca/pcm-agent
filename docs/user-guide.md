## 1. 功能介绍

AI 智能助手是工时管理系统的内置对话机器人，支持通过自然语言完成以下操作：

| 功能 | 说明 | 示例 |
|------|------|------|
| 工时查询 | 查询自己或下属的工时记录 | "查一下我本周的工时" |
| 项目查询 | 查看项目列表和基本信息 | "我参与了哪些项目" |
| 周报生成 | 自动汇总工时数据并生成 Markdown 周报 | "帮我生成上周的周报" |
| 工时填报 | 直接通过对话填报工时 | "填报今天8小时到项目A" |
| 知识问答 | 解答工时制度、假期政策等问题 | "年假怎么申请" |

---

## 2. 如何打开 AI 助手

登录系统后，点击页面右下角的 **💬 AI 助手** 按钮，聊天窗口会从右侧弹出。

- 点击 **×** 关闭窗口，对话历史会保留
- 窗口支持拖拽调整位置
- 每次登录会自动恢复上次的对话记忆

## 3. 工时查询

### 查询自己的工时

直接描述时间范围即可，无需指定姓名：

```
你：查一下我本周的工时
你：上个月我总共填报了多少小时
你：今天的工时
```

### 查询他人工时（管理员）

部门管理员可以查询本部门员工的工时：

```
你：查一下张三本周的工时
你：李四上个月的工时情况怎样
```

### 支持的时间表达

| 说法 | 含义 |
|------|------|
| 今天、今日 | 当天 |
| 本周、这周 | 本周一至今 |
| 上周 | 上周一至上周日 |
| 本月、这个月 | 本月1日至今 |
| 上个月、上月 | 上月完整数据 |
| 3月、3月份 | 指定月份 |
| 3月1日到3月15日 | 自定义日期范围 |

### 查询结果示例

```
📊 工时查询结果
查询时间：2026-03-17 至 2026-03-26
总工时：38.5 小时，共 9 条记录

各项目工时：
- 工时管理系统：24.5 小时（5 天）
- 内部培训：8 小时（2 天）
- 行政事务：6 小时（2 天）
```

## 5. 周报生成

AI 助手会自动汇总你的工时数据，生成格式化的 Markdown 周报，可以直接复制使用。

### 生成本周周报

```
你：帮我生成本周周报
你：生成周报
```

### 生成指定周的周报

```
你：生成上周的周报
你：生成3月第2周的周报
```

### 周报格式示例

```markdown
# 工作周报 | 2026年第12周（03/16-03/22）

## 工时概览

| 项目 | 工时（h）| 占比 |
|------|---------|------|
| 工时管理系统 | 32 | 80% |
| 内部培训 | 8 | 20% |
| **合计** | **40** | **100%** |

## 工作总结

本周主要投入工时管理系统的 AI 助手功能开发，完成了知识库检索模块的升级和
Prompt 管理系统的实现。同时参与了团队技术分享培训。
```

## 6. 工时填报

### 基本填报

描述项目、日期、工时和工作内容即可：

```
你：填报今天在工时管理系统项目8小时，完成了AI助手开发
你：帮我填一下昨天的工时，项目是工时管理系统，4小时
```

### 填报规则

| 规则 | 说明 |
|------|------|
| 工时步长 | 必须是 0.5 小时的整数倍（如 0.5、1、1.5、2……） |
| 最大工时 | 单次填报不超过 24 小时 |
| 日期限制 | 不能填写未来日期 |
| 项目 | 需要是系统中已存在的项目 |

### 填报示例对话

```
你：帮我填今天的工时，8小时，工时管理系统，完成了周报生成功能
助手：✅ 工时填报成功！
      日期：2026-03-26
      项目：工时管理系统
      工时：8.0 小时
      描述：完成了周报生成功能
```

## 7. 知识库问答

AI 助手内置了公司工时管理制度和常见问题知识库，可以直接提问：

```
你：工时填报的截止时间是什么时候
你：请假需要提前多久申请
你：加班工时怎么认定
你：年假有多少天
你：出差期间怎么填工时
```

回答会注明**来源文档**，方便核对原文：

```
根据工时填报管理制度，每月工时应在次月5日前完成填报。
超过截止时间需要联系部门管理员进行审批补录。

📚 来源：工时填报管理制度.md
```

## 8. 多轮对话与记忆

### 上下文理解

AI 助手支持多轮对话，可以理解指代词和省略表达：

```
你：查一下张三本周的工时
助手：张三本周工时：32小时...

你：那上周呢          ← 自动理解"张三的上周"
助手：张三上周工时：40小时...

你：再查一下李四      ← 切换查询对象
助手：李四本周工时：...
```

### 长期记忆

助手会记住你的常用偏好，下次对话自动应用：

- 常用项目名称
- 习惯的查询时间范围
- 个人工号或标识

### 清除对话历史

如需开始全新对话，可以说：

```
你：清除对话记录
你：重新开始
```

## 9. 常见问题 FAQ

**Q：AI 助手看不到我的工时数据怎么办？**

A：请确认登录状态正常，工时数据已在系统中填报。若确认数据存在但查询不到，请联系系统管理员检查账号权限。

---

**Q：填报工时时提示"项目不存在"？**

A：项目名称需要与系统中完全一致，建议先用"查看我的项目"确认项目名称后再填报，也可以直接说项目 ID。

---

**Q：工时必须是 0.5 的整数倍，填 1.3 小时会怎样？**

A：系统会提示填报失败并说明原因，重新输入符合规则的工时即可。

---

**Q：AI 助手能帮我修改或删除已填报的工时吗？**

A：目前 AI 助手仅支持**填报**工时，修改和删除请在工时管理页面手动操作。

---

**Q：知识库的内容不准确或过时怎么办？**

A：请联系系统管理员更新知识库文档（`knowledge-base/` 目录），更新后无需重启，知识库会自动重新加载。

---

**Q：对话回复速度很慢？**

A：AI 助手依赖外部 LLM 服务，响应时间受网络状况影响。一般情况下工具查询在 3 秒内返回，知识问答在 5-10 秒内返回。若长时间无响应，请刷新页面重试。

---

**Q：我问的问题 AI 助手不理解怎么办？**

A：可以尝试：
1. 换一种说法，尽量描述清楚时间、对象、操作
2. 拆分复杂问题，逐步提问
3. 如果是制度相关问题，直接在系统文档中查询
