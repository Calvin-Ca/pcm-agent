# 工时填报插件 · 使用文档

在 **Claude Code / Codex 命令行**里,根据你**当前代码仓库的 git 提交**自动生成工时并填报。
一句话:进任意仓库打 `/workhour:fill-workhour 上周`,核对草稿、说「确认」,工时就填好了。

---

## 一、它怎么工作

```
/workhour:fill-workhour 上周
  → 读你当前仓库的 git 历史(只统计你自己的提交)
  → 按天聚合、估算工时、归纳工作内容 → 出一张草稿表
  → 你核对工时、指定项目
  → 出「预览」(还没写库)
  → 你说「确认」 → 才真正写入你的工时账户
```

- **只填你本人**:身份由你的钉钉 ID 决定,填不到别人账上。
- **二段确认**:不确认就绝不写库,不会误填。
- **读 git 在本地跑,写库经内网网关** → ai-service → 工时系统。

---

## 二、前提条件

1. Claude Code 能正常使用(能 `/login` 登录、能正常对话)。
2. 机器在**研发内网**,能访问:
   - `172.19.2.176:8929`(GitLab,装插件用)
   - `172.19.3.136:8765`(工时网关,写库用)
3. 你有自己的**钉钉 userid**(见第四步)。

---

## 三、安装(每人一次)

### 1. 装插件(无需 GitLab 账号)

```bash
claude plugin marketplace add http://172.19.2.176:8929/root/workhour_mcp.git
claude plugin install workhour
```

### 2. 配置你的钉钉 ID(唯一要配的值)

**Mac / Linux(zsh)**:
```bash
echo 'export WORKHOUR_ENTITY_ID="你的钉钉userid"' >> ~/.zshrc && source ~/.zshrc
```

**Windows(PowerShell)**:
```powershell
[Environment]::SetEnvironmentVariable("WORKHOUR_ENTITY_ID", "你的钉钉userid", "User")
```

### 3. 完全重启 Claude Code

**不是 `/clear`,是彻底退出进程再重开**——插件命令和网关在启动时才加载。
Windows 上要**开一个新终端**再启动 `claude`(环境变量才生效)。

### 4. 验证

```bash
claude plugin list          # 应看到 workhour@workhour-mcp ✔ enabled
```
Claude Code 里输入 `/mcp` → 应看到 `workhour-gateway` 是 `connected` + `authenticated`。

---

## 四、怎么查自己的钉钉 userid

`WORKHOUR_ENTITY_ID` 填的是一串**数字**(形如 `52351731171085063`),不是手机号、不是姓名。

- 钉钉管理后台查自己的 userid;或
- 找管理员在 workhour 库执行:
  ```sql
  SELECT entity_id FROM sys_user WHERE user_phone = '你的手机号';
  ```

## 五、日常使用

进入你要填工时的**代码仓库目录**,开 Claude Code,输入:

```
/workhour:fill-workhour 上周
```

时间范围随便说:`本周` / `最近3天` / `6月` / `2026-06-01 到 2026-06-15`。

然后:
1. Claude 给你一张**草稿表**(日期 / 工时 / 归纳的工作内容 / 项目待定)。
2. 你核对工时、告诉它**记到哪个项目**(直接说项目名即可)。
3. 它给出**预览**(还没写库)。
4. 你说「**确认**」→ 才真正入库,返回记录 ID。

### 示例

```
你：/workhour:fill-workhour 上周
Claude：（草稿）2026-06-30 ×1 提交 +149/-41 → 建议 0.5h：补全 API 文档
你：按 7.5，安居华富北项目
Claude：（预览）2026-06-30 7.5h，项目 安居华富北 → 已解析成 ID，填报人=你本人
你：确认
Claude：✅ 填报成功，记录 ID 34e4b122-...
```

## 六、安全须知

- **测试阶段**:想试功能,走到「预览」就停,**别说「确认」**——预览不写库,安全。
- 一旦「确认」,会往**真实工时表**插记录(填错了可在系统里删)。
- 插件只会填**你本人**的工时。

## 七、常见问题

| 现象 | 原因 | 解决 |
|------|------|------|
| `Unknown command: /fill-workhour` | 命令带插件名前缀 | 用 `/workhour:fill-workhour`(打 `/` 从菜单选) |
| 命令菜单里没有它 | 装完没重启 | **彻底退出** Claude Code 再重开;`claude plugin list` 确认已装 |
| `/mcp` 里网关不是 connected | 网络不通 / 变量没生效 | 确认能连 `172.19.3.136:8765`;重启终端和 Claude Code |
| 写库报 401 / 换不到 token | 钉钉 ID 没配或填错 | 确认 `WORKHOUR_ENTITY_ID` 是数字 userid;重启后 `echo $WORKHOUR_ENTITY_ID` 验证 |
| `Please run /login` 403 | Claude Code 没登录 | 先 `/login`;登不上多半是连不到外网 `api.anthropic.com`,配代理/白名单 |
| 项目名没解析成 ID | 项目名写得和系统不一致 | 用系统里的准确项目名;或先在系统查到再填 |
